**Method signature:**
```python
def backup_to_xer(self, output_path) -> Path:
    """
    Export current project to XER for backup purposes.

    Unlike export_to_xer which uses self.output_dir, this method
    writes directly to the user-specified path.

    Backup is on-demand only (per user decision). Claude does NOT
    automatically backup before edits -- user must explicitly request.

    Args:
        output_path: Full path (str or Path) for the XER backup file

    Returns:
        Path to the created XER backup file

    Raises:
        P6ExportError: If backup fails
    """
```

**Implementation:**
1. Convert output_path to Path: `output_path = Path(output_path).resolve()`
2. Ensure parent directory exists: `output_path.parent.mkdir(parents=True, exist_ok=True)`
3. Add .xer extension if missing
4. Log: `"Creating XER backup: {output_path}"`
5. Temporarily override `self.output_dir` to `output_path.parent`, call `self.export_to_xer(output_path.name)`, then restore original output_dir
   - Alternative approach: duplicate the export logic inline. But reusing export_to_xer is cleaner.
   - Use try/finally to ensure output_dir is restored even on failure
6. Verify file was created: check `output_path.exists() and output_path.stat().st_size > 0`
7. Log file size in KB
8. Return the output_path

**No changes to existing methods.** backup_to_xer is purely additive.
